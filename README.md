# اشتراک صفحه گوشی (Kotlin) — نمایش و کنترل از Chrome

تصویر صفحهٔ گوشی با **H.264 سخت‌افزاری** کدگذاری می‌شود و از طریق وای‌فای به Chrome می‌رسد
(دیکود سخت‌افزاری با WebCodecs). کلیک، کشیدن، اسکرول، دکمه‌های برگشت/خانه/اخیر و تایپ از Chrome
روی گوشی اجرا می‌شود. هیچ رمزی لازم نیست.

## ساخت APK با GitHub

1. در GitHub یک ریپوی خالی بسازید.
2. محتویات همین پوشه (نه خود فایل zip) را در ریپو قرار دهید. پوشهٔ مخفی `.github` حتماً باید برود:

```
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```

3. در تب **Actions** گردش‌کار **Build APK** خودکار اجرا می‌شود (یا Run workflow را بزنید).
4. بعد از سبز شدن، از پایین صفحهٔ اجرا فایل **ScreenShare-APK** را دانلود کنید؛ داخلش `app-debug.apk` است.

## نصب و استفاده

1. APK را روی گوشی نصب کنید (نصب از منابع ناشناس را اجازه دهید).
2. برنامه را باز کنید و **باز کردن تنظیمات دسترسی‌پذیری** را بزنید، سرویس «اشتراک صفحه» را روشن کنید.
   - اندروید ۱۳ به بالا برای برنامه‌های نصب‌شده بیرون از فروشگاه: تنظیمات ← برنامه‌ها ← اشتراک صفحه ← منوی ⋮ ← **Allow restricted settings**، بعد دوباره سرویس را روشن کنید.
3. **شروع اشتراک** را بزنید و در پنجرهٔ اجازه، **کل صفحه (Entire screen)** را انتخاب کنید.
4. آدرس نمایش‌داده‌شده (مثل `https://192.168.1.20:8443`) را در Chrome کامپیوتر باز کنید.
   بار اول هشدار گواهی می‌آید: **Advanced ← Proceed**. (گواهی خودامضا روی خود گوشی ساخته می‌شود؛
   Chrome فقط در https اجازهٔ دیکود سخت‌افزاری ویدیو را می‌دهد.)

دو دستگاه باید روی یک وای‌فای باشند (یا کامپیوتر به هات‌اسپات گوشی وصل شود).

## نکته‌ها

- **کیفیت:** از منوی بالای صفحه (سریع / بالا / خیلی بالا). پیش‌فرض «بالا» حدود ۱۰ تا ۱۲ مگابیت بر ثانیه است. وای‌فای ۵ گیگاهرتز بهتر است.
- **کشیدن:** حرکت وقتی اجرا می‌شود که دکمهٔ ماوس را رها کنید (محدودیت سرویس دسترسی‌پذیری). برای اسکرول، چرخ ماوس راحت‌تر است.
- **چرخش صفحه** به‌طور خودکار دنبال می‌شود.
- **امنیت:** چون رمز ندارد، هر کسی در همان شبکه که آدرس را بداند می‌تواند ببیند و کنترل کند. فقط روی شبکهٔ مطمئن استفاده کنید و بعد از کار «توقف اشتراک» را بزنید.

## وقتی VPN روی گوشی روشن است

برنامه خودش را به شبکهٔ وای‌فای می‌بندد تا VPN جلوی اتصال کامپیوتر را نگیرد. اگر باز هم قطع شد:

- در برنامهٔ VPN، «اشتراک صفحه» را از تونل مستثنی کنید (Per-app / Bypass apps) یا گزینهٔ «Bypass LAN» را روشن کنید.
- گزینهٔ سیستمی «Block connections without VPN» (Lockdown) را خاموش کنید؛ این گزینه اجازهٔ دور زدن VPN نمی‌دهد.
- اگر خود کامپیوتر هم VPN دارد، شبکهٔ محلی (192.168.x.x) را در VPN کامپیوتر مستثنی کنید.
- اگر از هات‌اسپات گوشی استفاده می‌کنید، بستن به وای‌فای ممکن نیست؛ در این حالت استثنا کردن برنامه در VPN لازم است.
